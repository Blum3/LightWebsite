Comment Rejoindre et Utiliser le Webring IDE

Qu'est-ce qu'un webring ? Un webring est une collection de sites web reliés entre eux de manière circulaire, permettant aux visiteurs de naviguer d'un site à l'autre en cliquant sur des boutons "next" et "previous". C'est un excellent moyen de découvrir des contenus de niche et de soutenir d'autres créateurs !

Qu'est-ce qu'IDE ? Interactive Design and Experience : C'est le nom d'un Master spécialisé de Gobelins / Cnam-Enjmin (le site de la formation).

1. Candidature

Pour être accepté sur le webring IDE, il n'y a qu'une seule condition : être ou avoir été étudiant dans cette formation. Votre site n'a pas besoin d'avoir de référence directe à la formation.

Envoyez votre demande par mail à mason.galilee@gmail.com. Vous serez ajouté à l'index, vous serez alors atteignable via les widgets des autres sites du webring.

2. Implémentation

Une fois approuvé, il faut ajouter quelques lignes de code à votre site web.

Le widget : Collez cet extrait à l'endroit où vous souhaitez faire apparaître le widget du webring sur votre site.

<div id='ide-webring'>
    <script type="text/javascript" src="https://galilee-mason.neocities.org/ide-webring/onionring-variables.js"></script>
    <script type="text/javascript" src="https://galilee-mason.neocities.org/ide-webring/onionring-widget.js"></script>
</div>

Le style : Collez cet extrait dans votre balise <head> dans index.html. 

<link rel="stylesheet" href="https://galilee-mason.neocities.org/ide-webring/onionring.css">

Ce webring se base sur onionring.js, un grand merci à eux !
